# ML Module - Retail KPI Intelligence Platform

This directory contains machine learning models, training scripts, and forecasting pipelines:
- **Prophet Sales Forecasting**: 7-day and 30-day time-series demand models.
- **Scikit-learn Analytics**: RFM customer segmentation and SKU clustering.
- **Feature Engineering**: Retail calendar seasonality, holiday regressors, and lag features.

Scheduled for activation in **Phase 9: ML Analytics + Forecasting**.
